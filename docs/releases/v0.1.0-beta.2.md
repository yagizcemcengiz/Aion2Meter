# Aion2Meter Beta

**Beta software: protocol coverage is Partial. Supported events are counted conservatively; unsupported events may be omitted.**

Live-tested Windows x64 WPF combat overlay for AION 2.

## Highlights

- Self damage and CURRENT DPS tracking.
- Validated party DPS, arbitrary manual party members invited by Self, and five-player Quick Join / matchmaking groups.
- Remote party damage attribution and automatic class detection where authoritative profile evidence exists.
- Scene/backend identity rebinding and stale CURRENT party cleanup after group dissolution.
- Compact overlay, diagnostics export and passive approximate RTT display.
- Native WPF class badges: GL / TE / RA / AS / SP / SO / CL / CH / ?. The previous development PNGs are no longer embedded or distributed.

## Live verified

Solo combat, manual party joins, sequential arbitrary players, five-player Quick Join dungeon, remote party DPS, boss combat damage accounting, dungeon exit/group cleanup and world/scene transitions.

## Requirements

- Windows x64.
- Npcap installed separately.
- Extract the entire ZIP and run `Aion2Meter.App.exe`. The self-contained package includes .NET; no separate .NET Runtime, SDK or Visual Studio installation is needed.
- Start the meter before entering the server/world. If already in-world, return to Server Selection and re-enter.

## Known limitations

- Protocol coverage is Partial; combat category `0x36` remains Unsupported.
- Joining an already-existing party may occasionally require a zone/scene refresh before all party members appear.
- Boss Meter, Overall/session statistics and Effective Healing/HPS are not included yet.
- Future or unseen protocol variants may require additional validation.

The initial roster issue above is not claimed fixed. It is not proven to affect Self inviting players, Quick Join, normal dungeon party DPS or remote damage attribution. No speculative party changes were made for this release.

## Architecture

Passive network observation only: no memory reading, DLL injection, game hooks, packet modification/injection, macros or anti-cheat bypass. Random Other exclusion and no-backfill remain preserved.

Diagnostic JSON stays local unless you choose to share it. It can contain character names and network endpoints; review before sharing.

## Distribution

Download `Aion2Meter-v0.1.0-beta.2-win-x64.zip` and verify it using `Aion2Meter-v0.1.0-beta.2-SHA256.txt`. Dependency licenses/notices and PacketDotNet corresponding-source information are included in the ZIP. Npcap and the previous development class PNGs are not bundled. Beta.1 history is unchanged.

Next development phase, after this release: Boss Meter research using the existing diagnostics/screenshots. No Boss Meter implementation is included here.
