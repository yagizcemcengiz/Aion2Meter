# Development class icons

These eight PNGs were supplied by the user for development. Their provenance/license has not been independently established here. They can be replaced at the same filenames before a public release.

The App packages `*.png` in this directory as WPF resources. `ClassIconCatalog` caches frozen bitmaps and hides Unknown, undefined classes and missing assets. No absolute filesystem path or runtime asset copy is required. The class enum is separate from the icon artwork; the live projection currently publishes Unknown because no generic class resolver has been independently validated.
